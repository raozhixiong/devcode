# 龙虾（Lobster）- 表设计（SQLite 全量 Schema）

> 版本：v1.0 | 依据：《05-龙虾-核心设计.md》
> 数据库：SQLite（WAL, busy_timeout=5000, foreign_keys=ON）；Flyway 迁移（V1__init.sql 起）
> 布局：共享库 `~/.lobster/lobster.db` + 每 agent 库 `~/.lobster/agents/<agentId>/agent.db`
> 约定：主键为带前缀 ULID（ses_/msg_/prt_/run_/tsk_/evt_…）；时间戳 INTEGER 毫秒；JSON 字段 TEXT 存 JSON 字符串

---

## 一、共享库（lobster.db）

### 1.1 用户与认证

```sql
-- 用户（企业成员）
CREATE TABLE user (
  id            TEXT PRIMARY KEY,              -- usr_
  username      TEXT NOT NULL UNIQUE,
  display_name  TEXT NOT NULL,
  email         TEXT,
  avatar_url    TEXT,
  role          TEXT NOT NULL,                 -- developer|reviewer|tester|pm|ops|approver|knowledge|admin
  status        TEXT NOT NULL DEFAULT 'active',-- active|disabled
  created_at    INTEGER NOT NULL,
  updated_at    INTEGER NOT NULL
);

-- 网关令牌
CREATE TABLE auth_token (
  id            TEXT PRIMARY KEY,              -- tok_
  name          TEXT NOT NULL,
  token_hash    TEXT NOT NULL,                 -- SHA-256，原文不存
  scopes        TEXT NOT NULL,                 -- JSON: ["operator.read",...]
  created_by    TEXT REFERENCES user(id),
  created_at    INTEGER NOT NULL,
  expires_at    INTEGER,
  revoked_at    INTEGER
);

-- 配对设备
CREATE TABLE device (
  id            TEXT PRIMARY KEY,              -- dev_
  label         TEXT,
  role          TEXT NOT NULL,                 -- operator|node
  public_key    TEXT NOT NULL,
  platform      TEXT,
  access        TEXT NOT NULL,                 -- full|limited|node
  approved_at   INTEGER,
  last_seen_at  INTEGER,
  created_at    INTEGER NOT NULL
);
CREATE TABLE device_pairing_request (
  id            TEXT PRIMARY KEY,
  device_id     TEXT,
  status        TEXT NOT NULL,                 -- pending|approved|rejected|superseded
  scopes        TEXT,                          -- JSON
  created_at    INTEGER NOT NULL,
  resolved_at   INTEGER
);
```

### 1.2 Agent 注册表

```sql
CREATE TABLE agent (
  id            TEXT PRIMARY KEY,              -- agt_
  name          TEXT NOT NULL,                 -- "developer-01"
  kind          TEXT NOT NULL DEFAULT 'agent', -- agent|system
  role          TEXT NOT NULL,                 -- developer|reviewer|...
  emoji         TEXT,
  avatar_url    TEXT,
  workspace_dir TEXT NOT NULL,
  db_path       TEXT NOT NULL,
  model_provider TEXT,
  model_id      TEXT,
  utility_model TEXT,
  permission_rules TEXT NOT NULL,              -- JSON Ruleset: [{permission,pattern,action}]
  tool_profile  TEXT,                          -- coding|messaging|custom
  skills_allowlist TEXT,                       -- JSON 数组，NULL=全部
  subagent_depth INTEGER NOT NULL DEFAULT 1,
  hidden        INTEGER NOT NULL DEFAULT 0,
  created_via   TEXT,                          -- operator|agent
  created_at    INTEGER NOT NULL,
  updated_at    INTEGER NOT NULL
);

-- agent 与用户绑定（谁可以操作哪个 agent）
CREATE TABLE agent_binding (
  agent_id      TEXT NOT NULL REFERENCES agent(id) ON DELETE CASCADE,
  user_id       TEXT NOT NULL REFERENCES user(id) ON DELETE CASCADE,
  can_write     INTEGER NOT NULL DEFAULT 1,
  PRIMARY KEY (agent_id, user_id)
);

-- 频道绑定（入口路由到 agent）
CREATE TABLE channel_binding (
  id            TEXT PRIMARY KEY,
  channel       TEXT NOT NULL,                 -- webhook|wecom|dingtalk|feishu|email
  account_id    TEXT NOT NULL,
  agent_id      TEXT NOT NULL REFERENCES agent(id),
  config        TEXT,                          -- JSON
  created_at    INTEGER NOT NULL,
  UNIQUE (channel, account_id)
);
```

## 二、每 Agent 库（agents/\<id\>/agent.db）

### 2.1 会话与消息（OpenCode 模型 + OpenClaw 概念）

```sql
CREATE TABLE session (
  id            TEXT PRIMARY KEY,              -- ses_
  session_key   TEXT NOT NULL,                 -- main|group:xx|cron:xx|worktree:xx
  parent_id     TEXT REFERENCES session(id),   -- 子代理父会话
  session_scope TEXT NOT NULL DEFAULT 'conversation',
  kind          TEXT NOT NULL DEFAULT 'other', -- main|group|cron|hook|worktree|subagent|dashboard
  title         TEXT,
  icon          TEXT,
  category      TEXT,                          -- 自定义分组名
  pinned        INTEGER NOT NULL DEFAULT 0,
  directory     TEXT NOT NULL,                 -- 工作目录
  worktree      TEXT,                          -- JSON {id,branch,repoRoot}
  agent_id      TEXT,                          -- 跨 agent fork 来源
  model_provider TEXT, model_id TEXT,
  permission_rules TEXT,                       -- 会话级 Ruleset JSON
  approved_rules TEXT,                         -- 运行时 always 积累 JSON
  queue_mode    TEXT NOT NULL DEFAULT 'steer', -- steer|followup|collect|interrupt
  revert_state  TEXT,                          -- JSON
  compaction_baseline TEXT,                    -- 上下文纪元基线 partId
  created_actor TEXT,                          -- JSON {type:human|agent,id}（不可变）
  owner         TEXT,                          -- JSON {type,id,assignedBy,assignedAt}
  unread        INTEGER NOT NULL DEFAULT 0,
  state_version INTEGER NOT NULL DEFAULT 0,
  archived_at   INTEGER,
  tokens_input  INTEGER NOT NULL DEFAULT 0,
  tokens_output INTEGER NOT NULL DEFAULT 0,
  cost          REAL NOT NULL DEFAULT 0,
  share_url     TEXT,
  spawned_by    TEXT,
  created_at    INTEGER NOT NULL,
  updated_at    INTEGER NOT NULL
);
CREATE UNIQUE INDEX idx_session_key ON session(session_key) WHERE archived_at IS NULL;
CREATE INDEX idx_session_parent ON session(parent_id);
CREATE INDEX idx_session_category ON session(category, updated_at);

CREATE TABLE session_participant (           -- 参与者历史（≤32）
  session_id    TEXT NOT NULL REFERENCES session(id) ON DELETE CASCADE,
  actor_type    TEXT NOT NULL,                 -- human|agent|channel-sender
  actor_id      TEXT NOT NULL,
  last_at       INTEGER NOT NULL,
  PRIMARY KEY (session_id, actor_type, actor_id)
);

CREATE TABLE message (
  id            TEXT PRIMARY KEY,              -- msg_
  session_id    TEXT NOT NULL REFERENCES session(id) ON DELETE CASCADE,
  role          TEXT NOT NULL,                 -- user|assistant
  data          TEXT NOT NULL,                 -- JSON：V1MessageData（model/cost/tokens/finish/agent…）
  created_at    INTEGER NOT NULL,
  updated_at    INTEGER NOT NULL
);
CREATE INDEX idx_msg_session ON message(session_id, created_at, id);

CREATE TABLE part (                          -- 事件源（append-only）
  id            TEXT PRIMARY KEY,              -- prt_
  session_id    TEXT NOT NULL,
  message_id    TEXT NOT NULL REFERENCES message(id) ON DELETE CASCADE,
  type          TEXT NOT NULL,                 -- text|reasoning|tool|file|step-start|step-finish|snapshot|patch|agent|subtask|compaction|retry
  data          TEXT NOT NULL,                 -- JSON：对应 Part 结构
  created_at    INTEGER NOT NULL
);
CREATE INDEX idx_part_msg ON part(message_id, id);
CREATE INDEX idx_part_session ON part(session_id, id);

CREATE TABLE session_input (                 -- 输入收件箱
  id            TEXT PRIMARY KEY,
  session_id    TEXT NOT NULL REFERENCES session(id) ON DELETE CASCADE,
  prompt        TEXT NOT NULL,                 -- JSON Prompt
  delivery      TEXT NOT NULL,
  admitted_seq  INTEGER NOT NULL,
  promoted_seq  INTEGER,
  created_at    INTEGER NOT NULL,
  UNIQUE (session_id, admitted_seq)
);

CREATE TABLE session_active_writer (         -- writer claim 围栏
  session_key   TEXT PRIMARY KEY,
  run_id        TEXT NOT NULL,
  generation    TEXT NOT NULL,                 -- 随机代际 token
  claimed_at    INTEGER NOT NULL
);

CREATE TABLE todo (
  session_id    TEXT NOT NULL REFERENCES session(id) ON DELETE CASCADE,
  position      INTEGER NOT NULL,
  content       TEXT NOT NULL,
  status        TEXT NOT NULL,                 -- pending|in_progress|completed
  priority      TEXT NOT NULL DEFAULT 'medium',
  updated_at    INTEGER NOT NULL,
  PRIMARY KEY (session_id, position)
);

CREATE TABLE branch (                        -- transcript 分支
  id            TEXT PRIMARY KEY,
  session_id    TEXT NOT NULL REFERENCES session(id) ON DELETE CASCADE,
  leaf_entry_id TEXT,
  name          TEXT,
  is_active     INTEGER NOT NULL DEFAULT 0,
  created_at    INTEGER NOT NULL
);
```

### 2.2 事件溯源

### 2.3 记忆索引（FTS5 + 向量可选）

```sql
CREATE TABLE memory_source (
  id            TEXT PRIMARY KEY,
  path          TEXT NOT NULL,                 -- workspace 相对路径
  tier          TEXT NOT NULL,                 -- instructions|curated|episodic|prospective|review
  updated_at    INTEGER NOT NULL,
  UNIQUE (path)
);
CREATE TABLE memory_chunk (
  id            TEXT PRIMARY KEY,
  source_id     TEXT NOT NULL REFERENCES memory_source(id) ON DELETE CASCADE,
  chunk_index   INTEGER NOT NULL,
  content       TEXT NOT NULL,
  origin_class  TEXT NOT NULL,                 -- owner|transcript|import   <- provenance 闸门列
  embedding     BLOB,                          -- 可选向量（sqlite-vec）
  created_at    INTEGER NOT NULL
);
CREATE INDEX idx_chunk_source ON memory_chunk(source_id);
CREATE VIRTUAL TABLE memory_fts USING fts5(content, content='memory_chunk', content_rowid='rowid');

CREATE TABLE standing_intent (
  id            TEXT PRIMARY KEY,
  text          TEXT NOT NULL,
  trigger       TEXT NOT NULL,                 -- JSON 触发条件
  status        TEXT NOT NULL DEFAULT 'active',
  expires_at    INTEGER,
  created_at    INTEGER NOT NULL
);
CREATE VIRTUAL TABLE standing_intent_fts USING fts5(text, content='standing_intent', content_rowid='rowid');
```

## 三、跨库访问规则

| 数据 | 库 | 访问方式 |
|---|---|---|
| 会话/消息/Part/事件 | agent.db | SessionService（持 agent 专属连接池） |
| 任务/审批/看板/cron | lobster.db | TaskService 单写 |
| 用户/agent 注册/设备 | lobster.db | 启动加载 + 变更事件失效 |
| 记忆索引 | agent.db | MemoryService + FTS5 |
| 快照/截断输出 | 文件系统 | 引用存表（snapshot/tool-output 目录） |

## 四、数据保留与清理策略

| 数据 | 保留 | 清理方式 |
|---|---|---|
| durable event | 永久（会话删除级联） | 会话删除时 cascade |
| tool-output 文件 | 7 天 | 每小时清理线程 |
| snapshot | 会话活跃期 + 30 天 | 日清理 |
| audit_event | 30 天 / 10 万行 | 日清理 |
| approval（已决） | 30 天 | 日清理 |
| cron_run | 90 天 | 日清理 |
| memory_chunk 向量 | 跟随 source | 源删除级联 |

## 五、迁移策略

- Flyway：共享库 `db/migration/shared/V*.sql`；agent 库 `db/migration/agent/V*.sql`（新建 agent 库时全量跑 + schema_meta 记录版本）
- 兼容原则：只做加列（ADD COLUMN + DEFAULT）、新表；破坏性变更走新表+迁移脚本+旧表 DROP 三步
- 备份：`VACUUM INTO 'backup-<ts>.db'` + workspace 目录归档
