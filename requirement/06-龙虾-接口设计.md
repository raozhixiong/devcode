# 龙虾（Lobster）- 接口设计（全量 API 规范）

> 版本：v1.0 | 依据：《05-龙虾-核心设计.md》
> 传输：HTTP REST（`/api/*`，JSON）+ WebSocket 帧协议（`/ws`）；认证：`Authorization: Bearer <token>` / WS connect.auth
> 命名风格：资源路径小写中划线；响应统一 `{data}` 或 `{error:{code,message,details}}`

---

## 一、WebSocket 帧协议（`ws://127.0.0.1:18790/ws`）

### 1.1 帧格式

```json
// 请求
{"type":"req","id":"r-001","method":"chat.send","params":{...},"idempotencyKey":"k1"}
// 响应-成功
{"type":"res","id":"r-001","ok":true,"payload":{...}}
// 响应-失败
{"type":"res","id":"r-001","ok":false,"error":{"code":"MISSING_SCOPE","message":"...","details":{"missingScope":"operator.write"},"retryable":false}}
// 事件（服务端推送）
{"type":"event","event":"session.next.text.delta","payload":{...},"seq":1042,"stateVersion":7}
```

### 1.2 握手

```json
// 首帧必须 connect
{"type":"req","id":"c-1","method":"connect","params":{
  "client":{"id":"web","version":"1.0.0","platform":"web"},
  "role":"operator",
  "scopes":["operator.read","operator.write"],
  "auth":{"token":"<网关令牌>"},
  "device":{"id":"<指纹>","publicKey":"...","signature":"...","nonce":"<服务端挑战>","signedAt":1737264000000}
}}
// 服务端先下发挑战
{"type":"event","event":"connect.challenge","payload":{"nonce":"...","ts":1737264000000}}
// 成功 -> hello-ok
{"type":"res","id":"c-1","ok":true,"payload":{"protocol":1,"policy":{"maxPayload":1048576},"features":{"methods":[...],"events":[...]}}}
```

副作用方法（chat.send/sessions.*写操作/tasks.cancel…）必须带 `idempotencyKey`。

## 三、核心接口的数据契约

### 3.1 chat.send 响应流（时序）
```
res: {runId, status:"started"}
event: session.next.prompt.admitted
event: session.next.step.started {model, snapshot?}
event: session.next.text.delta ×N（打字机）
event: session.next.tool.called {callID, tool:"bash", input:{command}}
event: session.next.tool.progress {structured:{lines}}   ← 卡片实时刷新
event: session.next.tool.success {content:[{type:"text",text:"..."}]}
event: permission.asked（如触发）-> permission.replied -> 继续
event: session.next.step.ended {tokens, cost, files}
event: session.status {type:"idle"}
```

### 3.2 Part JSON（chat.history 消息结构）
```json
{
  "id":"msg_01H...", "sessionID":"ses_...", "role":"assistant",
  "time":{"created":1737264000000},
  "model":{"providerID":"openai-compat","modelID":"glm-5.3"},
  "tokens":{"input":1200,"output":300,"reasoning":0,"cache":{"read":8000,"write":0}},
  "cost":0.003, "finish":"stop",
  "parts":[
    {"type":"reasoning","text":"..."},
    {"type":"text","text":"分析如下..."},
    {"type":"tool","tool":"bash","callID":"call_1",
     "state":{"status":"completed","output":"✓ 12 passed","title":"npm test","metadata":{"exitCode":0}}},
    {"type":"step-finish","reason":"stop","tokens":{...}}
  ]
}
```

### 3.3 错误码表
| code | HTTP | 场景 |
|---|---|---|
| INVALID_REQUEST | 400 | 参数/schema 错 |
| INVALID_CURSOR | 400 | 分页游标 |
| UNAUTHORIZED | 401 | 令牌无效 |
| MISSING_SCOPE | 403 | 权限不足（details.missingScope） |
| NOT_FOUND | 404 | 资源不存在 |
| CONFLICT | 409 | 重复提交/状态冲突 |
| RATE_LIMITED | 429 | retryAfterMs |
| CONTEXT_OVERFLOW | 413 | 触发压缩 |
| UNAVAILABLE | 503 | 网关忙（retryable） |
| IDEMPOTENCY_REPLAY | 409 | 同 key 重放返回上次结果 |

## 四、对外扩展接口

### 4.1 Webhook 入站（频道适配）
```
POST /hooks/{channel}/{accountId}
Header: X-Lobster-Signature: sha256=...
Body: 频道适配器约定格式
-> 路由到绑定 agent 的会话（DM 共享 main/群组隔离），触发 auto-reply run
```

### 4.2 工具插件 SPI（Java）
```java
public interface ToolPlugin {
  String id();
  List<Tool> tools(PluginContext ctx);   // 注册时注入
}
// 打包 lobster-tool-*.jar 放 ~/.lobster/plugins/ 自动加载
```

### 4.3 MCP 客户端配置（lobster.json）
```json
{
  "mcp": {
    "servers": {
      "company-wiki": {"type":"stdio","command":"npx","args":["-y","mcp-wiki"],
        "enabled": true, "sessionOverride": false}
    }
  }
}
```
