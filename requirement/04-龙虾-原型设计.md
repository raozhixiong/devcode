**会话行状态徽章**（从左到右叠放）：
| 徽章 | 含义 |
|---|---|
| •蓝点 | 未读 |
| ⏳ | Queued（等并发槽，tooltip "等待并发槽"） |
| ✏️ | 草稿（有未发送文本） |
| 🌐 | 云/远程 worker |
| 👤→👤+N | owner 头像叠栈（owner 在前+参与者） |
| ○环绕头像 | 在线观众（live presence） |
| 🟠 | agent 请求关注（TTL 琥珀图标） |
| ▸2 | 子会话树（点击展开父子关系） |

会话行右键菜单：固定/取消、已读未读、重命名、指派给我/指派给…、设图标、Fork、复制 ID、移动分组、归档、删除。支持 Cmd/Ctrl 多选 + Shift 范围选 -> 批量操作栏。

### 2.2 消息流渲染规范

**用户消息**（右对齐，角色色边框）：
```
┌────────────────────────────┐
│ 帮我修复登录页的空指针        │  <- hover 显示 [⏪rewind] 
└────────────────────────────┘      右键: Rewind/Fork from here
```

**Assistant 消息**（左对齐）按 Part 顺序渲染：

| Part 类型 | 渲染 |
|---|---|
| ReasoningPart | 折叠行 `💭 思考了 12s` 点击展开 markdown |
| TextPart | markdown 流式（代码高亮/表格/ conceal） |
| ToolPart-running | 单行 `⠋ Read src/auth.ts` spinner |
| ToolPart-completed | 见 2.3 工具卡片 |
| ToolPart-error | 单行删除线 + 红色错误码 |
| StepFinish | 细分隔行 `step 3 · 1.2k tok · $0.003` |
| SnapshotPart | `📷 快照 3 files` 可展开 diff |

**工具卡片两形态**：
- **InlineTool**（单行）：`→ Read src/foo.ts` / `→ Grep "SessionManager"` / `→ Glob **/*.ts`；denied 时删除线+🔒
- **BlockTool**（左侧色条面板）：
```
┃ $ npm test                                    [▾折叠]
┃   ✓ 12 passed (3.2s)
┃   …(默认折叠至 3 行，点击展开)
┃ → Edit src/auth.ts +12 -3
┃ ┃ ```diff
┃ ┃ - if (user.name == null) {
┃ ┃ + if (user == null || user.name == null) {
┃ ┃ ```
┃ 连续调用折叠: "Ran 13 commands, read 6 files" (点击展开)
```

### 2.4 Composer 细节

- `+` 能力菜单：Skills 开关 / Connectors（MCP 会话级启用 + Add MCP server 作用域选择）/ Web search / Manage plugins
- `@` 补全：文件路径（fuzzy）/ agent 名 / 模型
- `/` 斜杠命令：与键位系统同源注册（/compact /new /plan /agents /model …）
- `⌘K`：命令面板（跨角色会话搜索 + 全部命令 + 导航）
- 粘贴图片/文件 -> 附件卡；拖入目录 -> 树形摘要

### 2.5 Plan 模式交互

- 切 plan：顶栏 pill 变 `📖 PLAN MODE 只读`；每次 reminder 注入
- 计划文件渲染：`.lobster/plans/*.md` 专用视图（大纲+checkbox 进度）
- 模型调 plan_exit -> 弹确认 `计划完成，切换到 build 执行？` -> Yes 自动切 agent 并注入执行消息

### 2.6 统一侧面板

| 标签 | 内容 |
|---|---|
| Terminal | xterm.js PTY 多标签；Ctrl+` 快捷；断线重挂 300s |
| Files | 线程文件/项目文件树 + 变更徽章 |
| Browser | 远程浏览器快照 + Annotate/Inspect 标注卡 |
| Tasks | 后台子代理任务 rail（实时状态+inspector） |
| Review | 评审视图（diff/评论） |
| Side chat | companion 侧问（不干扰主运行，/btw /side） |

## 五、关键交互流程

### 5.1 发送消息（开发者）
```
输入 -> (斜杠命令? 直接执行) -> chat.send WS
  -> 立即 ack {runId,status:started} -> 乐观消息上屏
  -> WS event: session.next.prompt.admitted
  -> session.next.text.delta (流式打字机)
  -> session.next.tool.called -> 卡片 running
  -> [权限 ask] -> 弹窗 -> reply -> 继续
  -> session.next.step.ended (tokens/cost)
  -> finish=stop -> 历史刷新合并
```

### 5.2 运行中插话（steer）
```
运行中输入 -> 队列模式判定(steer)
  -> 原子注入活跃 run（当前工具完成后生效）
  -> 消息标记 "已插入运行"
```

### 5.3 子代理后台任务
```
模型调 task(background) -> 返回 "已启动 task_xxx 勿轮询"
  -> 右侧 Tasks rail 出现条目(实时状态)
  -> 完成 -> 合成 user 消息注入 -> 父循环自动恢复
```

## 六、响应式与主题

- ≥1440px：三栏全展开；1024~1440：侧面板下停靠；<1024：侧边栏抽屉化+面板 overlay
- 主题 token：primary/error/diffAdded/diffRemoved/markdown*/syntax* 等 60 语义 token；三内置主题 JSON + 自定义导入
- 状态色：running=primary 旋转、queued=灰沙漏、error=红、success=绿、denied=删除线灰
