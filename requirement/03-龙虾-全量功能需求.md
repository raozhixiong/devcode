# 龙虾（Lobster）企业级 AI 工作台 — 全量功能需求规格说明书

> 版本：v1.0 | 日期：2026-08-25
> 产品定位：本地启动的企业级多角色 AI 工作台。主体功能镜像 OpenClaw（Gateway/多 agent/频道/任务/记忆/看板），开发者角色的代码能力对齐 OpenCode（工具系统/Part 模型/权限/子代理）。
> 技术栈：Java 21（Spring Boot 3）+ HTML/Lit/HTMX 前端 + SQLite（本地单文件）+ WebSocket
> 参考文档：《01-opencode-功能与核心设计.md》《02-openclaw-功能与核心设计.md》

---

## 一、产品概述

### 1.1 产品愿景
一个本地部署、企业内网可用的 AI 工作台。**开发者**是最大角色，获得完整的 AI 编程能力（对话式编程、工具调用、子代理、Plan 模式）；**流程工作人员**（产品、测试、运维、审核、项目管理等）获得角色化工作台（任务看板、审批、频道沟通、文档处理、自动化）。所有角色共享同一 Gateway 内核与统一数据底座。

### 1.2 角色体系（RBAC + Agent 映射）

| 角色 | 说明 | 主要界面 | 能力来源 |
|---|---|---|---|
| **developer（开发者）** | 最大角色，全量代码能力 | IDE 式工作台（左会话树+中对话+右侧面板：终端/文件/浏览器/任务） | OpenCode 镜像 |
| reviewer（评审员） | 代码评审、PR 审查、diff 查看 | 看板 + 评审工作台 | OpenClaw |
| tester（测试员） | 用例生成、测试执行、缺陷管理 | 任务看板 + 测试工作台 | OpenClaw |
| pm（项目经理） | 任务分配、进度跟踪、看板管理 | Workboard + Dashboard | OpenClaw |
| ops（运维） | 沙箱管理、自动化、监控 | Automations + 日志 + 审批 | OpenClaw |
| approver（审批员） | 权限审批、exec 审批、安全 | 审批中心 | OpenClaw |
| knowledge（知识管理员） | 记忆库维护、技能工坊 | Memory + Skills | OpenClaw |
| admin（系统管理员） | 用户/配置/设备/集成管理 | 设置中心 | OpenClaw |

每个角色绑定一个或多个 **Agent 定义**（= OpenClaw 的 agent = 完整隔离域：workspace + bootstrap 文件 + 权限 + 模型配置）。同一角色可实例化多个 agent。

### 1.3 总体架构（需求级）

```
┌───────────────────────────────────────────────────────┐
│ 浏览器（HTML + Lit 组件 + WebSocket 客户端）             │
│  开发者工作台 │ 流程工作台 │ 看板 │ 审批 │ 设置 │ 管理后台 │
├───────────────────────────────────────────────────────┤
│ Gateway 守护进程（Spring Boot 单进程，本地 :18790）        │
│  ├─ HTTP API（REST）+ WebSocket（req/res/event 帧协议）  │
│  ├─ 会话路由 & 命令队列（lane FIFO + steer/followup 模式）│
│  ├─ Agent 运行时（Agent Loop / LLM Provider 层）          │
│  ├─ 工具系统（内置 20+ 工具 + 权限 + 沙箱 + MCP）          │
│  ├─ 事件总线（durable + live 双通道，SSE/WS 推送）          │
│  └─ 插件/技能/定时任务/频道适配（Webhook/邮件/IM 可扩展）    │
├───────────────────────────────────────────────────────┤
│ SQLite（lobster.db + 每 agent 库）+ 文件系统 workspace    │
└───────────────────────────────────────────────────────┘
```

## 二、功能需求总表

### 模块 A：核心运行时（对齐 OpenCode）

#### A1. Agent Loop（代理循环）
- FR-A1-1 用户消息经 `session.prompt` 持久化入 session_input 收件箱后调度循环
- FR-A1-2 循环：取有效上下文 -> 终止检查 -> 注入 reminders -> 组装工具 -> 调用 LLM -> 流式落库 -> 工具执行 -> 结果回填 -> 继续/终止
- FR-A1-3 每 step 记录 tokens/cost/耗时；step.finish=tool-calls 则继续
- FR-A1-4 请求失败按错误分类重试（rate limit 退避/5xx/上下文溢出自动压缩后重试）
- FR-A1-5 中断：随时 abort，孤儿工具调用补 "[Tool execution was interrupted]"

#### A2. 消息 Part 模型
- FR-A2-1 消息 = User | Assistant；Assistant 含 model/cost/tokens/finish 元数据
- FR-A2-2 Part 13 种：text / reasoning / tool(四态 pending→running→completed/error) / file / step-start / step-finish / snapshot / patch / agent / subtask / compaction / retry / synthetic
- FR-A2-3 流式 delta 与全量分离（delta 事件实时广播，ended 事件可回放）
- FR-A2-4 上下文压缩：序列化历史→LLM 摘要→CompactionPart 替代；保留近 N token（默认 usable×0.25，clamp 2k~15k）；压缩后旧工具输出标记清理

#### A3. 提示词组装
- FR-A3-1 分层组装：①身份提示（角色 agent prompt 或厂商模板）②env 块（模型/cwd/git/platform/日期）③指令文件（全局+项目 AGENTS.md，findUp 首个命中）④MCP 指令 ⑤技能清单
- FR-A3-2 **cache 边界**（OpenClaw 借鉴）：稳定段（身份/规则/工具说明/bootstrap）在边界上，易变段（日期/频道上下文/运行时信息）在边界下
- FR-A3-3 动态 reminders 注入最后一条 user 消息（plan 模式提醒/模式切换提醒/编辑器选区 `<system-reminder>`）
- FR-A3-4 每 agent 的 bootstrap 文件注入（AGENTS.md 指令/SOUL.md 人格/IDENTITY.md 身份/USER.md 用户画像/MEMORY.md 记忆；预算：单文件 20k 字符、总 60k，截断提示）

#### A4. 工具系统（开发者全量，对齐 OpenCode）
- FR-A4-1 内置工具 20+：read / write / edit / apply_patch / glob / grep / bash(powershell/shell) / process / lsp / task(子代理) / question(问用户) / todo / webfetch / websearch / skill / plan_enter / plan_exit / sessions_spawn / sessions_yield / subagents / message / ask_user / progress_card / cron / image / pdf / structured_output
- FR-A4-2 工具定义：id + description(txt) + JSON Schema 参数 + execute(args, ctx{sessionID, abort, metadata(), ask()})
- FR-A4-3 工具按角色/agent 过滤（reviewer 无 write/edit；tester 有限 bash；developer 全量）
- FR-A4-4 **task 工具 description 动态拼入可用子代理列表**（"- explore: 只读快速检索…"）
- FR-A4-5 输出截断：默认 2000 行/50KB，超限保留头尾+全文落盘 tool-output 目录+提示委托 explore 处理
- FR-A4-6 图片归一化（resize 到模型限制）；provider 媒体兼容层（不支持的工具结果媒体拆为合成 user 消息）
- FR-A4-7 MCP 客户端：动态加载 MCP server 工具 + resource 三件套（list/read/templates）
- FR-A4-8 工具执行前后钩子（before_tool_call block 终止语义 / after_tool_call / tool_result_persist 落盘前转换）

#### A5. 权限系统（三层规则）
- FR-A5-1 Rule = {permission, pattern, action: allow|deny|ask}；eval：agent.permission + session.permission + 会话内 approved 取 findLast 匹配；无匹配默认 ask
- FR-A5-2 ask 流程：挂起请求→事件推送→UI 弹窗（一次/始终/拒绝+反馈）→Deferred 恢复；always 写入会话 approved 并放行同批其他 pending
- FR-A5-3 默认权限模板按角色：developer `*:allow, *.env*:ask`；reviewer `edit:deny`；每角色可覆盖
- FR-A5-4 doom loop 检测：连续 3 次同名同参调用触发 ask
- FR-A5-5 exec 审批中心：一阶段审批注册表（request/get/list/resolve/waitDecision），保留 30 天历史

#### A6. 子代理（OpenCode 机制 + OpenClaw 扩展）
- FR-A6-1 Task 工具：depth 限制（默认 1）、权限继承（deny 下传、task/todowrite 默认禁递归）、task_id 续传、XML 包装结果 `<task id state><summary/><task_result/></task>`、提示词级 trust 声明
- FR-A6-2 内置子代理：explore（只读检索）/ general（多步研究）/ plan（只读规划）/ title / summary / compaction
- FR-A6-3 sessions_spawn（OpenClaw）：非阻塞生成隔离子会话；model/timeout/上下文 fork/visible 看板会话；完成后 announce 推送回请求者
- FR-A6-4 sessions_yield：结束当前轮等子代理结果作为下一条消息（免轮询）
- FR-A6-5 后台子代理：异步运行，完成时合成 user 消息注入父会话并重新触发循环（"不要 sleep/轮询，会自动通知"）
- FR-A6-6 子代理深度≥2 时编排型子代理获得 spawn/list/history 工具
- FR-A6-7 子代理 prompt 模式：minimal（省略记忆/输出指令/心跳等段）

#### A7. 模式系统（Plan/Build）
- FR-A7-1 plan 模式 = 权限裁剪（edit 全 deny，仅可写 plans/*.md）+ plan.txt reminder 注入 + plan_exit 交接工具 + UI 事件联动自动切换
- FR-A7-2 plan→build 切换注入 build-switch.txt（"执行计划文件"合成消息）

#### A8. LLM Provider 层
- FR-A8-1 多 provider：OpenAI 兼容（含火山方舟/DeepSeek/智谱/Kimi）/ Anthropic 兼容 / Ollama 本地 / 自定义 baseURL
- FR-A8-2 模型目录（model catalog）+ 限制（context/output）+ 成本配置；utility model 分离（标题/摘要/小任务用低成本模型）
- FR-A8-3 流式 SSE 解析→统一 LLMEvent 归一化→Part 落库
- FR-A8-4 工具调用修复（大小写/坏调用路由 invalid 工具让模型重写）
- FR-A8-5 双运行时可选：SDK 路径 / 原生 HTTP 直连（企业内网代理适配）

### 模块 B：会话与协作（对齐 OpenClaw）

#### B1. 会话管理
- FR-B1-1 会话路由：本地工作台会话（developer/reviewer 等角色各自默认会话域）；接入频道时按 DM/群组/cron/webhook 隔离
- FR-B1-2 队列模式：steer（注入活跃运行）/ followup（排队）/ collect（合并单轮）/ interrupt（中止跑最新）；500ms debounce
- FR-B1-3 会话操作：重命名/图标/贴图钉/归档（先围栏后提交）/恢复/删除/fork/rewind 到某消息/分支切换
- FR-B1-4 **writer claim 围栏**：run 持久化 activeWriterRunId，所有 transcript 写入校验
- FR-B1-5 三层归属：Creator（不可变）/ Owner（可指派）/ Participants（≤32 历史）；按 owner 过滤与"涉及我"
- FR-B1-6 会话分组：自定义组（名称+顺序，gateway 同步）、Coding 区（worktree 绑定会话显示 repo⎇branch）、Pinned
- FR-B1-7 状态感知：stateVersion + changesSince 事件；watcher（spawn 父/显式 watch）收合并通知
- FR-B1-8 会话 diff 面板：分支按钮打开逐文件 diff（增删改统计/折叠/统一分栏/全部 vs 未提交 vs 单 commit）

#### B2. 多角色 Agent 管理
- FR-B2-1 agent CRUD（= 角色实例）：名称/emoji/头像/workspace/model/权限/技能 allowlist/绑定频道
- FR-B2-2 每 agent 独立：workspace 文件、状态库、auth profiles、会话域
- FR-B2-3 Agents 页 7 面板：overview（身份/模型/fallback/配置）/ files / tools / skills / channels / cron / memory
- FR-B2-4 agent 生命周期事件与运行状态（active runs/心跳）

#### B3. 频道接入（企业内网 IM 适配）
- FR-B3-1 内置适配：Webhook 通用 / 邮件 / 企业微信 / 钉钉 / 飞书（插件式，可扩展）
- FR-B3-2 每频道账号绑定到 agent（binding 路由）；DM 默认共享 main，群组隔离
- FR-B3-3 allowlist 安全（白名单发送者/群组）；消息出站钩子
- FR-B3-4 频道状态页（内置+插件状态、登录、配置）

### 模块 C：任务与自动化

#### C1. 任务台账（Task Registry）
- FR-C1-1 统一 TaskRecord：taskId、runtime(subagent/acp/cron/cli)、requester/owner、状态机 queued→running→succeeded/failed/timed_out/cancelled/lost、投递状态、通知策略(done_only/state_changes/silent)、进度摘要、错误、明细 JSON
- FR-C1-2 tasks.list/get/cancel RPC；聊天内 Background tasks rail
- FR-C1-3 工具调用计数与最后工具名展示

#### C2. Workboard 看板
- FR-C2-1 状态列：triage/backlog/todo/scheduled/ready/running/review/blocked/done
- FR-C2-2 卡片：优先级/标签/指派 agent/链接 task-run-session/执行元数据/尝试/评论/链接/证明/附件/诊断/通知/模板/归档/事件历史
- FR-C2-3 视图预设与空列隐藏、agent 过滤器、卡片详情 modal、状态持久化
- FR-C2-4 dashboard 会话：sessions_spawn visible:true 创建的持久面板会话（Dashboards 页列表）

#### C3. 自动化（Cron/心跳）
- FR-C3-1 cron CRUD + 手动 run + 运行历史（runId 过滤）
- FR-C3-2 heartbeat 心跳自我维护（agent 定期自检任务）
- FR-C3-3 wake 唤醒注入；运行收据（receipt）持久化
- FR-C3-4 Automations 页：统计卡（自动化数/失败数/调度器状态/下次唤醒）+ 自动化表 + 运行历史

### 模块 D：记忆与知识（对齐 OpenClaw 五层）

- FR-D-1 五层：Instructions（AGENTS.md 人写）/ Curated（MEMORY.md/USER.md Dreaming 晋升）/ Episodic（memory/日期.md + transcripts）/ Prospective（standing intents + cron）/ Review（DREAMS.md）
- FR-D-2 provenance 溯源列（owner 可信/transcript 不可信），晋升过确定性闸门
- FR-D-3 memory_search/memory_get 工具（FTS5 + 可选向量）；bare /new 时注入近期日记
- FR-D-4 Dreaming 后台整合（可开关、状态可查）
- FR-D-5 Memory 页：dreaming 状态/开关/Dream Diary/记忆导入（从其他工具迁移 plan/apply 流程）
- FR-D-6 USER.md 用户画像层（稳定偏好指令式，supersede 而非追加）

### 模块 E：开发者工作台界面（OpenCode 镜像，Web 化）

- FR-E-1 **布局**：左侧会话树（五级分区+状态徽章）| 中部对话流（居中框架：user 右/assistant 左+工具卡片）| 右侧统一面板（Terminal/Files/Browser/Tasks/Review/Side-chat，可停靠/扩容/状态按会话持久化）| 底部 composer（+能力菜单：技能/连接器/搜索开关 + N session overrides pill）
- FR-E-2 工具卡片类型感知渲染：bash 语法高亮命令+终端输出块；read/write/edit 单行图标+行号代码块+diff（+added -removed）；连续同类折叠摘要；pending spinner/denied 删除线；默认折叠 3~10 行可展开
- FR-E-3 markdown 流式渲染 + 代码高亮 + diff 双视图（宽屏 split）
- FR-E-4 Reasoning 折叠块（点击展开，显示时长）
- FR-E-5 权限弹窗：diff 预览 + 一次/始终/拒绝 三键 + feedback
- FR-E-6 斜杠命令与 @补全（@文件/@agent/模型）；⌘K 命令面板（跨角色会话搜索+导航）
- FR-E-7 Todo 侧栏（任务清单实时状态）；usage 统计（token/成本/上下文占用条）
- FR-E-8 Plan 模式交互：权限提示、计划文件视图、plan_exit 确认弹窗、自动切换 build
- FR-E-9 PTY 终端：多标签、attach/接管、16MiB 文件上传、断线重挂
- FR-E-10 PR/分支 chips：分支行+diff 大小+Create PR（接企业 Git）；会话 diff 面板
- FR-E-11 键位系统：命令=键位=斜杠三位一体；命令面板列出全部命令
- FR-E-12 会话行状态徽章全量：未读点/Queued 沙漏/草稿铅笔/云图标/子树展开/owner 头像叠栈/在线观众/attention

### 模块 F：流程工作台界面（OpenClaw 镜像）

- FR-F-1 各角色专属工作台首页（dashboard 会话 + 角色固定面板）
- FR-F-2 通用侧边栏（Pages/分组/Other/Coding）+ 会话工具栏（排序/分组/过滤/新建）
- FR-F-3 New Session 页：Place 选择器（本地目录/worktree 隔离+基分支）、角色选择、模型/推理级别、Incognito
- FR-F-4 Sessions 页：概览瓷砖+会话表+worktrees 标签+原生 CLI 目录（Claude/Codex 兼容会话列表）
- FR-F-5 Activity 页：Sessions 标签（按日分组+过滤+Inspect run）/ Live activity（脱敏工具活动）/ Run inspector（审计投影深链）
- FR-F-6 Usage 页：成本/用量（按 agent 聚合、日历桶、时序、日志）
- FR-F-7 Skills 页 + Skill Workshop（提案/评审/回滚/历史）
- FR-F-8 Devices 页（配对设备+节点+presence）、Plugins 页（已装+发现）、Portals、Apps

### 模块 G：安全与合规

- FR-G-1 认证：本地 token/密码（连接握手 auth）；用户 profile（显示名/头像/邮箱/GitHub 式身份）；可选 LDAP/SSO 适配插件
- FR-G-2 设备配对：connect 挑战签名、设备 token 轮换/吊销、scope 升级显式批准
- FR-G-3 Secrets 管理：团队作用域条目（env 值可见/secret 永不回显）、SecretRef 引用
- FR-G-4 沙箱（可选阶段二）：mode(off/non-main/all)、scope(agent/session/shared)、backend(docker/ssh)
- FR-G-5 审计台账：metadata-only（不含 prompt/消息体），30 天保留，10 万行上限
- FR-G-6 事件流脱敏：live activity 只记摘要与字段数，不存参数值
- FR-G-7 数据本地化：全部数据在本地 SQLite 与文件系统，无外部上报（遥测默认关闭）

### 模块 H：平台基础

- FR-H-1 WebSocket 帧协议：首帧 connect（挑战+签名）→ req{id,method,params}/res{id,ok,payload|error}/event{event,payload,seq,stateVersion}；idempotency key；MISSING_SCOPE 结构化错误
- FR-H-2 事件总线：durable（sessionID 聚合+seq，落库可回放）/ live（仅广播）；全局事件流订阅 + 会话级订阅
- FR-H-3 配置中心：schema 驱动（config.get/set/patch/apply + schema.lookup 路径查询 + reloadKind restart/hot/none）
- FR-H-4 插件系统：安装/启用/禁用/卸载（需重启提示）、MCP 服务器管理、插件贡献工具/频道/上下文引擎
- FR-H-5 可插拔 Context Engine：Ingest/Assemble/Compact/AfterTurn 四生命周期点 + 子代理钩子
- FR-H-6 日志：分级/文件轮转/logs.tail 游标；诊断（stability recorder）；OpenTelemetry 可选
- FR-H-7 备份与迁移：SQLite 备份策略、workspace 导出、记忆导入（plan/apply）
- FR-H-8 更新机制：本地版本检查、重启前挂起围栏（suspend.prepare/status/resume）、重启续跑（continuation queue）
